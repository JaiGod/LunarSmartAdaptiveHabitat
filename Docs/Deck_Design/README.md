# Deck Designer floor plan

The realistic Lunar Smart Adaptive Habitat laid out at true metre scale in the
[TimberTech Deck Designer](https://deckdesigner.timbertech.com/), plus the first
concept sketch with every health zone labelled.

| Module | Health role | Size |
|---|---|---|
| Core | Wardroom, exercise, hygiene, galley | 10.2 m octagon (≈ 86 m²) |
| 4 × crew quarters | Private sleep, mood lighting | 9.0 m octagons (≈ 67 m² each) |
| Command (N) | Work, life-support monitoring | 7.2 m octagon (≈ 43 m²) |
| Greenhouse (E) | Fresh food, planted space | 7.2 m octagon |
| Medical (W) | Med bay + radiation storm shelter | 7.2 m octagon |
| Airlock (S) | Suits, dust control | 7.2 m octagon |
| Tunnels | N/S 4.2 m wide, E/W 3.0 m wide | 7–10 m long |

Overall ≈ 43.6 m × 41.6 m, ≈ 655 m² of floor for a crew of 4.

The diagonal tunnels to the crew quarters are in the concept sketch. The deck
tool would not accept those diagonal joins, so in the final deck the quarters
stand as separate modules.
